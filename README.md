# minu-garden 🌸

App de escritorio para sesiones de estudio con jardín virtual.

## Stack
- **Frontend:** React 19 + TypeScript + Tailwind CSS 4
- **Desktop shell:** Tauri 2 (Rust)
- **Estado:** Zustand
- **Persistencia:** SQLite (próximamente)

## Dev

```bash
pnpm install
pnpm tauri dev
```

## Build

```bash
pnpm tauri build
```
