# Minu's Garden 🌸

App de escritorio para sesiones de estudio con jardín virtual.

## Stack

- **Frontend:** React 19 + TypeScript
- **Estilos:** CSS Vanilla (Custom Properties)
- **Desktop shell:** Tauri 2 (Rust)
- **Estado:** Zustand 5
- **Persistencia:** SQLite (via Rusqlite en Rust)

## Dev

```bash
pnpm install
pnpm tauri dev
```

## Build

```bash
pnpm tauri build
```
