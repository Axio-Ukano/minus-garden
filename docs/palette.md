# Minu's Garden - Paleta de colores

## Colores principales

| Token                  | Nombre            | Hex       | Uso                              |
| ---------------------- | ----------------- | --------- | -------------------------------- |
| `--color-bg`           | Fondo principal   | `#fceaf8` | Fondo de la app                  |
| `--color-panel`        | Paneles / cards   | `#fdf2fa` | Cards, sidebars, modales         |
| `--color-accent`       | Acento primario   | `#ff6bb5` | Botones principales, highlights  |
| `--color-accent-hover` | Acento secundario | `#ff1492` | Estado hover de botones          |
| `--color-text`         | Texto principal   | `#3b2f3f` | Texto de cuerpo                  |
| `--color-text-muted`   | Texto secundario  | `#bf8d8e` | Labels, placeholders, subtítulos |

## Colores semánticos

| Token             | Nombre             | Hex       | Uso                           |
| ----------------- | ------------------ | --------- | ----------------------------- |
| `--color-hearts`  | Corazones (moneda) | `#ffb8c1` | Icono y conteo de 💗          |
| `--color-success` | Éxito / progreso   | `#7acb8a` | Barra de progreso, completado |
| `--color-error`   | Error suave        | `#f295be` | Mensajes de error, alertas    |

## Colores del jardín

| Token           | Nombre           | Hex       | Uso                          |
| --------------- | ---------------- | --------- | ---------------------------- |
| `--color-grass` | Césped           | `#bde6c5` | Fondo del jardín, área verde |
| `--color-soil`  | Macetas / tierra | `#bf8d8e` | Macetas, bordes de tierra    |

## Uso en Tailwind (CSS custom properties)

```css
:root {
  --color-bg: #fceaf8;
  --color-panel: #fdf2fa;
  --color-accent: #ff6bb5;
  --color-accent-hover: #ff1492;
  --color-text: #3b2f3f;
  --color-text-muted: #bf8d8e;
  --color-hearts: #ffb8c1;
  --color-success: #7acb8a;
  --color-error: #f295be;
  --color-grass: #bde6c5;
  --color-soil: #bf8d8e;
}
```
