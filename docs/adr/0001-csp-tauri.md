# ADR-0001: Explicit CSP policy in Tauri

- **Status:** Accepted
- **Date:** 2026-04-27
- **Deciders:** @author

## Context

`src-tauri/tauri.conf.json` had `"csp": null`, acceptable for an offline app but not documented as a conscious decision. The frontend uses:

- External font "Press Start 2P" from `fonts.googleapis.com` (via `@import` in `src/styles/global.css`).
- Inline styles generated by React/Vite and by some components (`Panel.tsx`, etc.).
- Local assets served by Tauri via the `asset:` scheme and `https://asset.localhost`.
- IPC via `ipc:` and `http://ipc.localhost`.

Without an explicit CSP, a future inclusion of remote or dynamic content would be vulnerable to XSS with no safety net.

## Decision

Define a positive CSP in `tauri.conf.json` that permits exactly what the app uses today and blocks everything else:

```
default-src 'self';
img-src 'self' data: asset: https://asset.localhost;
media-src 'self' asset: https://asset.localhost;
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
font-src 'self' data: https://fonts.gstatic.com;
script-src 'self';
connect-src 'self' ipc: http://ipc.localhost
```

## Consequences

### Good

- Blocks `script-src` from any origin other than `'self'` by default — the foundation for defending against XSS if remote content ever enters.
- Acts as living documentation: reading the CSP tells you which origins the app loads from.
- Allows external audits to see explicit intent rather than "null".

### Bad

- `style-src 'unsafe-inline'` remains open because both Vite/React and BEM with inline styles require it. Tightening it would require adopting nonces or eliminating all `style={...}`.
- The Google font-src forces trusting third-party CDNs to serve the typeface.

### Neutral

- Any new external connection (telemetry, additional fonts, remote images) will require updating the CSP and recording the change.

## Considered Alternatives

### Keep `csp: null`

More permissive and "just works". Discarded for being opaque to reviewers and providing no defense in depth.

### Self-host the "Press Start 2P" font

Vendor the `.ttf`/`.woff2` in `public/` and remove `fonts.googleapis.com` and `fonts.gstatic.com` from the CSP. This is the natural next iteration; left as a follow-up because it changes the font loading flow and was out of scope for the tier S sprint.

## Notes

- Recommended smoke test after any change: `pnpm tauri dev` and `pnpm tauri build`, validate that the font loads, local assets are visible, and toasts appear after a simulated IPC failure.
